Undertone

A small, dependency-free procedural synth engine for game sound effects and pattern-based music. Browsers require a user gesture before audio can play — the AudioContext is created on your first click.

Pattern lab

Polyphonic cycles from mini-notation: [a b] subdivides, <a b> alternates per cycle, , stacks chords and layers, (3,8) is a euclidean rhythm, *2 doubles up, ~ rests. Pick an example (it starts looping), then edit everything live — including 7.1 surround placement if your hardware has it.
